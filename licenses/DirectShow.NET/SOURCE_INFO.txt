Building an interface-compatible replacement
--------------------------------------------
Extract the source archive to a working directory. The original build
projects are src/DirectShowLib-2005.csproj and src/DirectShowLib-2008.csproj.
Use the Release configuration, the supplied DShowNET.snk and a compatible
.NET Framework C# build environment. The source uses the generated assembly
version 2.1.0.*; for an in-place replacement of NX's existing strongly named
reference, set AssemblyVersion in your working copy to 2.1.0.0 and retain
the assembly name DirectShowLib-2005, signing key and compatible public API.
Keep your modifications in that working copy; this supplied archive is intact.

Close NX before substituting an interface-compatible modified library and
keep a backup of the previous DLL. Modification of the library and reverse
engineering to debug those modifications are not restricted by NX's
application-specific commercial-use or redistribution terms.

Verification scope
------------------
The included prebuilt DLL's identity, the source/project completeness and
signing-key correspondence were checked. A separate temporary Release library
was also compiled with the .NET Framework 4 C# compiler, USING_NET20, the
supplied signing key and AssemblyVersion set to 2.1.0.0 in the temporary copy.
Its assembly identity, all 822 types, 2,909 method signatures/attributes and
marshalling definitions, field/layout information and all 180 implemented
methods' normalized IL matched the existing DLL. This verifies source
correspondence, not bit-for-bit reproduction of the historical PE file.
No rebuilt library is installed by this patch; the source archive is unchanged.
